# WinDroid
WinDroid is an application for Android tablets that runs Windows 11 ARM using Java 6 and RAM emulation.
# Requirements
To run WinDroid, you need a tablet with a keyboard and mouse, 12 GB of RAM, at least 250 GB of free space, and Android 5.0 or higher.
