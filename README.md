# WinDroid

WinDroid is an Android application designed to emulate a Windows PC environment directly on Android devices using the V86 x86 emulator.

The project aims to bring the desktop Windows experience to Android tablets and smartphones.

## Features

- x86 PC emulation powered by V86.
- Virtual hard disk support.
- Virtual RAM configuration.
- Windows XP compatibility.
- Full-screen emulation interface.
- Keyboard and mouse support.

## Requirements

- Android 5.0 or higher.
- A compatible Android device.
- Sufficient available RAM for emulation.
- Available storage for Windows disk images and application files.
- Keyboard and mouse recommended for a better experience.

**Note:** Performance depends on the device's hardware and the Windows version being emulated.

## Installation

1. Download the latest WinDroid APK from the Releases section.
2. Install the APK on your Android device.
3. Make sure the required emulator files and disk images are available.
4. Launch WinDroid.
